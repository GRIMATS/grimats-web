Flujo especial

Control posterior de gastos menores E43

Un comprobante E43 aceptado por la DGII todavía debe mantenerse bajo control hasta completar su obligación posterior.

  1. Gasto registrado
  2. E43 generado
  3. Validación fiscal
  4. Pendiente de 606
  5. Listo para exportar
  6. 606 presentado
  7. Reconciliado

Alcance importante: los borradores dependen de que la información contable necesaria esté disponible y completa. Control Fiscal GRIMATS organiza y pregenera reportes; no presta por sí solo servicios contables, no presenta declaraciones ni reemplaza la revisión, firma, autorización o carga final ante la DGII.

Conversemos sobre tu caso
¿Necesito reemplazar mi sistema actual?

No necesariamente. La propuesta contempla un facturador web independiente y una API para integrar la operación en otra aplicación. Hay que evaluar tu sistema; desarrollar o adaptar ese conector es un alcance distinto del acceso a la API.

¿Qué diferencia hay entre el precio API y el precio con facturador?

El precio API corresponde al acceso para integrar la facturación en tu propio sistema. La modalidad con facturador GRIMATS incluye el portal para emitir y dar seguimiento a los comprobantes. La implementación de conectores nuevos se cotiza por separado.

¿Qué cuenta como un documento facturable?

En esta propuesta comercial, cada documento de producción aceptado se cuenta una sola vez. Una nota de crédito o débito aceptada cuenta por separado. Los reintentos, consultas de estado, acuses, copias PDF y pruebas no añaden cargos de emisión; tampoco se devuelve el consumo de una factura por emitir una nota de crédito. Pruebas y solicitudes técnicas quedan sujetas a límites de uso.

¿Cómo se calculan los comprobantes de compras y gastos?

Cada plan incluye un cupo mensual independiente para integrar comprobantes de compras y gastos. Si el consumo supera ese cupo, la capacidad adicional se agrega en paquetes completos de 250 comprobantes por US$6 cada uno; una fracción de paquete se redondea al paquete siguiente.

¿Hay planes estándar para integradores de software de terceros?

No. Los integradores deben contactarnos para validar el esquema técnico y comercial según su modelo, volumen y alcance.

¿La mensualidad incluye certificado e implementación?

No. Se cotizan aparte el certificado digital, los conectores nuevos, el acompañamiento de certificación, las migraciones y la implementación aplicable. Las condiciones de soporte, almacenamiento y conservación documental deben quedar expresas en la contratación.

¿Puedo ofrecerlo bajo la marca de mi aplicación?

Podemos evaluar esa modalidad como un esquema especial para integradores de software de terceros. La viabilidad, responsabilidades y condiciones se validan antes de presentar una propuesta. No se transfiere la propiedad del motor ni una autorización fiscal. Cada contribuyente conserva sus requisitos de habilitación. Consultar los requisitos publicados por la DGII.

¿Esta página ya permite contratar y emitir?

No. Es una propuesta visual y comercial de un producto en preparación. No emite comprobantes, no procesa pagos y no acredita certificación o autorización ante la DGII. La disponibilidad, el alcance, las pruebas y las autorizaciones se validarán antes de cualquier operación productiva.
