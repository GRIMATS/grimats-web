DATOS Y PÁGINAS DE PRUEBA — NO USAR EN PRODUCTIVO — RIESGO
Material para revisar dirección visual, contenido y recorrido. No es un sitio operativo.

CÓMO ABRIR
1. Extrae el ZIP completo.
2. Abre ABRIR_COMPARADOR.html en un navegador de escritorio.
3. Elige una propuesta. Los controles permiten alternar escritorio, tableta y móvil.
4. También puedes abrir cada HTML individual con doble clic.
No requiere instalar software, servidor local, cuenta, librerías ni acceso a internet.
Las imágenes, el CSS y el JavaScript están incluidos dentro de cada HTML.
Los HTML individuales pueden compartirse por separado y siguen funcionando sin conexión.

SEGURIDAD Y LÍMITES DE LA DEMO
No contiene claves, credenciales, integraciones, formularios conectados, analítica,
píxeles, almacenamiento local, cookies ni solicitudes de red.
No se incluye teléfono ni correo real accionable. No se envían mensajes.
No hay inventario, precios, pagos, pedidos, reservas ni atención comercial activa.
Los datos de los ejemplos están predefinidos. No introduzcas información real.
La página incluye etiquetas noindex/nofollow y política CSP que bloquea conexiones
y envío de formularios. Noindex NO es autenticación ni control de acceso.
Los bloqueos técnicos reducen operaciones accidentales, no convierten el prototipo
en una aplicación lista para producción. No desplegar públicamente sin validación.
