# Contexto del proyecto — demo de identidad G-Salud

Fecha: 2026-09-17. Ámbito: este paquete estático, no el repositorio de la aplicación clínica.

## Objetivo
Comparar cuatro identidades de una misma aplicación: Cliniva, Atria Salud, Medinexa y Saluvia. Crear, además, una propuesta de `g-salud.html` como división de soluciones para el área de salud de GRIMATS.

## Arquitectura de marca solicitada
GRIMATS (corporativo) → G-Salud (división especializada) → aplicación con nombre propio, **Powered by G-Salud**.

Las cuatro marcas son alternativas, no cuatro productos disponibles. No se ha elegido un nombre definitivo. La nueva organización de marca se muestra como propuesta, no como un cambio ya publicado.

## Fuente del contenido
https://grimats.com/g-salud.html y https://grimats.com/, consultadas el 17-09-2026. Se priorizó el tarifario publicado sobre montos antiguos del chat. Los gráficos parten de las cuatro imágenes adjuntas por el usuario.

## Restricciones
No publicar, cambiar DNS, editar repositorios ni conectarse a Supabase. No usar datos reales de pacientes. No reemplazar `index.html`. No presentar acreditaciones, certificaciones o cumplimiento regulatorio no verificados. No crear testimonios, clientes, métricas de adopción o disponibilidad de marcas ficticios.

Los documentos adjuntos de estado, arquitectura, decisiones y seguridad contienen principalmente plantillas o marcadores, y no permiten confirmar el estado funcional del producto. Este demo no es una auditoría de la aplicación real.
