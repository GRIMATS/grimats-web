Los documentos homónimos incluidos aquí se crearon exclusivamente para esta entrega, no se recuperaron de un repositorio.

`git status` en el directorio de trabajo devolvió que no existe repositorio Git. No se pudieron revisar commits locales y no se escribieron commits ni cambios oficiales. No fue necesario acceder al repositorio privado para producir este demo independiente basado en la web pública y las imágenes.

## Distinciones importantes
- Los importes y la oferta son una fotografía de la página fuente, no una garantía de disponibilidad técnica o vigencia contractual.
- No se atribuyen testimonios, número de clientes o resultados clínicos a ninguna marca.
- La división G-Salud y la firma del producto reflejan la nueva estructura solicitada; la web pública aún no fue actualizada.
- No se verificaron registro de marca, uso previo del nombre o disponibilidad de dominio.
- El prototipo visual no registra pacientes, cobra, factura ni activa pruebas gratuitas.
