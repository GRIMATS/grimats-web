# Decisiones de esta actualización

## DEMO-DEC-001 — Selección de identidad
Se usan exclusivamente OrbisMed, Clynia, Nexomed y Mediora, con orden 1 a 4 según el ranking adjunto. La selección comprende cuatro propuestas ganadoras; no se declara una única marca final.

## DEMO-DEC-002 — Activos y mensajes
Se aprovechan los símbolos y las letras de los logotipos subidos. Se recortan y preparan como recursos web. Los cuatro lemas corresponden a las referencias adjuntas.
La firma comercial en las páginas sigue siendo **Powered by G-Salud**; GRIMATS respalda la división, no ocupa el nombre principal de la aplicación.

## DEMO-DEC-003 — Datos comerciales
Los planes y los cálculos se mantienen iguales al HTML previo. No se realiza una nueva consulta comercial de la web en esta tarea, no se redefinen cupos ni se utiliza el precio histórico de US$40 del chat.

## DEMO-DEC-004 — Entrega local
Se entregan un HTML autocontenido y un ZIP con las páginas, recursos y documentación. No se publica ni se reemplaza el sitio público. No se crea index.html ni se agregan rutas de marcas descartadas.
