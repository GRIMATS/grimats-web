# Changelog

## 2026-09-17 — Selección de las cuatro marcas ganadoras
Se actualiza el demo previo para incluir exclusivamente OrbisMed, Clynia, Nexomed y Mediora. Se aplica el orden del documento de ranking. Se preparan activos web de las imágenes suministradas y se actualizan nombres, rutas, lemas, paletas, detalles visuales, navegación, selector y referencias de G-Salud.

Se conservan las seis páginas, el catálogo comercial y las interacciones existentes. Se ajustan las ilustraciones de interfaz a los nuevos símbolos. Se corrigen los iconos del flujo de Nexomed y la posición decorativa de los píxeles de Mediora.

Se ejecutan validaciones estáticas, de sintaxis y en Chromium; se revisan capturas de escritorio y móvil y se genera la entrega autocontenida junto al ZIP de archivos separados. No se modifica producción.
