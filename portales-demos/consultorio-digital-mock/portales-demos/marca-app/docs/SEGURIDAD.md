# Seguridad del demo

No contiene claves, contraseñas, credenciales, tokens ni datos reales de pacientes. Las pantallas son ejemplos y no tienen backend.
No hay persistencia de información clínica, cookies ni herramientas de analítica. El diálogo utiliza datos de contacto introducidos por el usuario únicamente para preparar una URL de WhatsApp codificada; la aplicación no envía mensajes por sí sola. La apertura de un servicio externo requiere una acción del usuario.

La versión autocontenida valida la ventana emisora de los mensajes de navegación y la lista de rutas permitidas. Los enlaces externos se mantienen separados de la navegación local.
Las páginas incluyen noindex/nofollow/noarchive; esto es una indicación a buscadores, no una barrera de acceso.

Antes de publicar, revisar el repositorio real y su política de seguridad, activar las cabeceras apropiadas y confirmar destinos, condiciones, textos legales y permisos. Este prototipo no acredita cumplimiento sanitario, HIPAA o certificaciones.
